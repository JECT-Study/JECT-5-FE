# 게임 생성 페이지 E2E 테스트 시나리오

## 페이지 개요

- **URL**: `/create`
- **핵심 기능**: 게임 제작, 문제 관리, 이미지 업로드, 게임 저장

## 테스트 시나리오

### 1. 초기 렌더링 및 기본 상태

- **게임 이름 입력 필드**
  - 기본값 "게임1" 표시 확인
  - 클릭 시 focused 상태로 변경
  - 더블 클릭 시 텍스트 입력 모드로 전환
  - 1-30자 글자수 제한 적용

- **문제 추가 버튼**
  - 초기 상태에서 활성화 확인
  - 최대 50문제까지 생성 가능

- **게임 저장 버튼**
  - 필수 입력값 누락 시 비활성화 상태
  - 유효한 입력 시 활성화

- **닫기 버튼**
  - 이전 화면으로 이동 기능

### 2. 게임 이름 관리

- **기본 이름 설정**
  - "게임1" 기본값 확인
  - 동일한 이름 존재 시 자동 넘버링 (게임2, 게임3...)

- **이름 편집 기능**
  - 더블 클릭으로 텍스트 입력 모드 전환
  - 실시간 편집 가능

- **표시 규칙**
  - 최대 2줄까지 표시
  - 영역 초과 시 말줄임표(...) 처리
  - 글자수 제한 1-30자 적용

### 3. 문제 관리 기능

- **문제 추가**
  - "문제 추가" 버튼 클릭으로 새 문제 생성
  - 최대 50문제까지 생성 가능
  - 50문제 달성 시 버튼 비활성화

- **문제 편집**
  - 현재 편집 중인 문제는 selected 상태
  - 질문 입력 필드 (필수, 1-50자)
  - 답안 입력 필드 (필수, 1-50자)
  - 필수값 누락 시 '!' 이모지 표시

- **문제 리스트**
  - 생성된 문제들의 목록 표시
  - 문제 클릭 시 해당 문제 편집 화면으로 전환
  - 문제 질문 1줄 요약 표시 (영역 초과 시 ... 처리)

- **문제 삭제**
  - 휴지통 아이콘 버튼으로 문제 삭제
  - 문제 수 1개 이하 시 삭제 버튼 비활성화

### 4. 이미지 업로드 기능

- **업로드 조건**
  - 허용 포맷: JPG, JPEG, PNG
  - 권장 해상도: 1280x720px
  - 최대 용량: 2MB

- **업로드 프로세스**
  - 이미지 업로드 영역 클릭으로 파일 선택
  - 조건 불충족 시 에러 메시지 표시

- **기존 이미지 관리**
  - 이미지 존재 시 마우스 hover로 어두운 오버레이 표시
  - 클릭 시 재업로드 가능

### 5. 게임 저장 프로세스

- **저장 전 유효성 검증**
  - 필수 입력값 누락 시 저장 불가
  - 질문/답안 미입력 시 error 상태 표시

- **게임 저장 팝업**
  - "게임 저장" 버튼 클릭 시 팝업 표시
  - 문제 순서 이동 기능 (위/아래 버튼)
  - 맨 위/아래 문제는 해당 방향 버튼 비활성화

- **저장 완료**
  - "네" 버튼 클릭 시 게임 저장
  - 대시보드에 게임 추가 확인
  - `/dashboard` 페이지로 이동

### 6. 나가기 및 팝업 관리

- **닫기 아이콘 버튼**
  - 우측 상단 닫기 아이콘 클릭
  - "게임 만들기 - 나가기 팝업" 표시

- **나가기 팝업**
  - "아니요" 버튼: 팝업 닫기
  - "네" 버튼: 저장하지 않고 대시보드로 이동
  - 팝업 닫기 영역 클릭: 팝업 닫기

- **팝업 닫기 영역**
  - 배경 클릭으로 팝업 닫기 기능

### 7. 에러 처리

- **업로드 에러 팝업**
  - 이미지 업로드 조건 불충족 시 표시
  - "닫기" 버튼으로 팝업 닫기

- **서버 에러 팝업**
  - 서버 통신 실패 시 표시
  - "닫기" 버튼으로 이전 화면으로 이동

- **필수값 누락 팝업**
  - 필수 입력값 누락 시 표시
  - "닫기" 버튼으로 이전 화면으로 이동

### 8. 네비게이션 및 상태 관리

- **이전 화면 이동**
  - "닫기" 버튼 클릭 시 이전 화면으로 이동
  - 브라우저 뒤로가기 버튼 동작 확인

- **상태 유지**
  - 페이지 새로고침 시 입력 데이터 유지
  - 브라우저 뒤로가기 후 재진입 시 상태 복원

### 9. 접근성 및 사용성

- **키보드 네비게이션**
  - Tab 키로 모든 인터랙티브 요소 순회
  - Enter/Space 키로 버튼 클릭
  - Escape 키로 팝업 닫기

- **스크린 리더 지원**
  - 입력 필드의 aria-label 및 aria-describedby
  - 버튼의 접근성 이름
  - 에러 메시지의 aria-live 속성

- **포커스 관리**
  - 팝업 열림 시 포커스 트랩
  - 팝업 닫힘 시 원래 포커스 복원

## 우선순위

- **Critical**: 게임 이름 관리, 문제 CRUD, 게임 저장
- **High**: 이미지 업로드, 유효성 검증, 나가기 기능
- **Medium**: 접근성, 에러 처리, 상태 관리

## 테스트 데이터

- **기본 게임명**: "게임1", "게임2" 등
- **샘플 문제**: 질문과 답안이 포함된 테스트 데이터
- **이미지 파일**: 다양한 포맷과 크기의 테스트 이미지
- **에러 시나리오**: 서버 에러, 유효성 검증 실패 케이스

## 특별 고려사항

- **파일 업로드**: 실제 파일 시스템 접근이 필요한 테스트
- **상태 복잡성**: 여러 입력 필드와 상태의 조합 테스트
- **팝업 관리**: 여러 팝업의 중첩 및 우선순위 처리
- **데이터 지속성**: 페이지 이동 시 입력 데이터 보존
