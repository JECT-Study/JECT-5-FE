# 게임 생성 페이지 E2E 테스트 시나리오

## 페이지 개요

- **URL**: `/create`
- **핵심 기능**: 게임 신규 제작, 게임 수정, 문제 관리, 이미지 업로드

## 테스트 시나리오

### 1-1. 초기 렌더링 (게임 신규 제작)

- **로그인 여부 확인**
  - 로그인되지 않은 사용자는 접근 불가
  - 로그인되지 않았을 경우 alert 표시, 홈 화면으로 redirect

- **네비게이션 영역**
  - 로고 이미지 렌더링 확인
  - 게임 이름 입력 input 표시 (기본값 '새 게임')
  - ThemeToggle 버튼 표시 확인
  - '게임 저장' 버튼 표시 확인
  - Cross 버튼 표시 확인

- **질문 리스트 영역**
  - 초기에 기본 질문 하나 생성, 선택된 상태
  - 하단 '문제 추가하기 버튼' 표시 확인

- **파일 업로드 영역**
  - 파일 업로드 컴포넌트 표시 (업로드된 이미지 없음)

- **질문/답변 입력 영역**
  - '질문 입력', '답안 입력'을 각각 placeholder로 하는 Input 2개 표시 확인

### 1-2. 초기 렌더링 (게임 편집)

### 2. 게임 이름 관리

- **네비게이션 영역**
  - 게임 이름 입력 input에 게임 제목이 기본으로 표시

- **질문 리스트 영역**
  - 해당 게임의 질문 개수만큼 question 컴포넌트 생성
  - 그 중 첫 번째 question이 선택된 상태

- **파일 업로드 영역**
  - 파일 업로드 컴포넌트 표시 (질문에 등록된 image가 있을 경우 해당 이미지가 기본으로 표시)

- **질문/답변 입력 영역**
  - 문제에 대한 질문, 답변이 value로 들어가 있는 input 두 개 표시 확인

### 3. 문제 관리 기능

- **문제 추가**
  - "문제 추가" 버튼 클릭으로 새 문제 생성
  - 최대 50문제까지 생성 가능
  - 50문제 달성 시 버튼 비활성화

- **문제 편집**
  - 현재 편집 중인 문제는 selected 상태
  - 질문 입력 필드 (필수, 1-50자)
  - 답안 입력 필드 (필수, 1-50자)
  - 필수값 누락 시 '!' 이모지 표시

- **문제 리스트**
  - 생성된 문제들의 목록 표시
  - 문제 클릭 시 해당 문제 편집 화면으로 전환
  - 문제 질문 1줄 요약 표시 (영역 초과 시 ... 처리)
  - 문제가 여러 개 있는 경우, 문제 순서 이동 기능 (이미지 옆 위/아래 버튼)
  - 맨 위/아래 문제는 해당 방향 버튼 비활성화

- **문제 삭제**
  - 휴지통 아이콘 버튼으로 문제 삭제
  - 문제 수 1개 이하 시 삭제 버튼 비활성화

### 4. 이미지 업로드 기능

- **업로드 조건**
  - 허용 포맷: JPG, JPEG, PNG
  - 권장 해상도: 1280x720px
  - 최대 용량: 2MB

- **업로드 프로세스**
  - 이미지 업로드 영역 클릭으로 파일 선택
  - 조건 불충족 시 에러 overlay 표시

- **기존 이미지 관리**
  - 이미지 존재 시 마우스 hover로 어두운 오버레이 표시
  - 클릭 시 재업로드 가능
  - 오버레이 우측 상단 Cross 버튼 클릭으로 삭제 가능

### 5. 게임 저장 프로세스

- **저장 전 유효성 검증**
  - 필수 입력값 누락 시 저장 불가
  - 질문/답안 미입력 시 overlay 표시

- **게임 저장 팝업**
  - "게임 저장" 버튼 클릭 시 팝업 표시

- **저장 완료**
  - "네" 버튼 클릭 시 게임 저장
  - 대시보드에 게임 추가 확인
  - `/dashboard` 페이지로 이동

### 6. 나가기 및 팝업 관리

- **닫기 아이콘 버튼**
  - 우측 상단 닫기 아이콘 클릭
  - 나가기 팝업 표시

- **나가기 팝업**
  - "아니요" 버튼: 팝업 닫기
  - "네" 버튼: 저장하지 않고 대시보드로 이동

### 7. 에러 처리

- **업로드 에러 팝업**
  - 이미지 업로드 조건 불충족 시 표시
  - "닫기" 버튼으로 팝업 닫기

- **서버 에러 팝업**
  - 서버 통신 실패 시 표시
  - "닫기" 버튼으로 이전 화면으로 이동

- **필수값 누락 팝업**
  - 필수 입력값 누락 시 표시
  - "닫기" 버튼으로 이전 화면으로 이동

### 8. 네비게이션 및 상태 관리

- **이전 화면 이동**
  - "닫기" 버튼 클릭 시 이전 화면으로 이동
  - 브라우저 뒤로가기 버튼 동작 확인

- **상태 유지**
  - 페이지 새로고침 시 입력 데이터 유지
  - 브라우저 뒤로가기 후 재진입 시 상태 복원

## 우선순위

- **Critical**: 게임 이름 관리, 문제 CRUD, 게임 저장
- **High**: 이미지 업로드, 유효성 검증, 나가기 기능
- **Medium**: 에러 처리, 상태 관리

## 테스트 데이터

- **기본 게임명**: "게임1", "게임2" 등
- **샘플 문제**: 질문과 답안이 포함된 테스트 데이터
- **이미지 파일**: 다양한 포맷과 크기의 테스트 이미지
- **에러 시나리오**: 서버 에러, 유효성 검증 실패 케이스
