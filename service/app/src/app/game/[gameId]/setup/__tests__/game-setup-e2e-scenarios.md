# 참가자 설정 페이지 E2E 테스트 시나리오

## 페이지 개요

- **URL**: `/game/[gameId]/setup`
- **핵심 기능**: 팀 관리, 유효성 검증, 게임 시작

## 테스트 시나리오

### 1. 초기 렌더링 및 홈 버튼

- 초기 팀 목록(A팀, B팀) 렌더링 확인
- 팀명 수정 시 사이드바 실시간 업데이트
- 홈 로고 클릭 → 게임 시작 전 머물던 화면 (entry)로 이동

### 2. 팀 추가 기능

- "참가자 및 팀 추가하기" 버튼으로 C팀 생성
- 알파벳 순서로 기본 팀명 설정 확인
- 사이드바에 새 팀 추가 확인

### 3. 팀 삭제 기능

- 3팀 이상일 때: clear input 버튼으로 팀 삭제 가능
- 팀 삭제 후 사이드바에서 해당 팀 제거 확인

### 4. 최소 팀 수 제약

- 삭제 버튼 클릭해도 팀이 삭제되지 않음

### 5. 최대 팀 수 제약

- 추가 버튼 8번 클릭해서 10팀(A~J팀) 생성
- 10팀 달성 시 "참가자 및 팀 추가하기" 버튼 `disabled` 확인

### 6. 팀명 유효성 검증

- **빈 값**: 팀명 삭제 시 "팀명을 비워둘 수 없어요." 에러
- **길이 초과**: 31자 입력 시 "팀명은 30자까지만 가능해요." 에러
- **중복**: 동일 팀명 입력 시 "이미 사용중인 팀명이에요." 에러

### 7. 게임 시작 기능

- 유효한 팀명들: 게임 시작 버튼 활성화 → `/game/[gameId]/play` 이동
- 에러 존재 시: 게임 시작 버튼 `disabled` 상태

### 8. 나가기 기능 (Cross 버튼)

- 우측 상단 Cross 아이콘 클릭 → 나가기 다이얼로그 → 게임 시작 전 머물던 화면 (entry)로 이동

## 우선순위

- **Critical**: 팀 수 제약, 게임 시작
- **High**: 팀 CRUD, 유효성 검증
- **Medium**: 네비게이션
