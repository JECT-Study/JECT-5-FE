# 홈페이지 E2E 테스트 시나리오

## 페이지 개요

- **URL**: `/`
- **핵심 기능**: 네비게이션, 게임 목록 표시, 인증 상태별 UI 변경

## 테스트 시나리오

### 1. 초기 렌더링 (비로그인 상태)

- **네비게이션 영역**
  - 로고 이미지 렌더링 확인
  - "간편로그인해서 게임 만들기" 버튼 표시
  - 카카오 로고 아이콘 포함 확인
  - 테마 토글 버튼(태양 아이콘) 표시

- **히어로 섹션**
  - "모두가 가볍게 즐길 수 있는 라이트 레크레이션" 제목 표시

- **게임 섹션**
  - "어떤 게임으로 시작해 볼까요?" 섹션 제목 표시
  - 게임 카드 4개 로딩 상태 표시 (스켈레톤 UI)
  - 로딩 완료 후 실제 게임 카드 4개 표시

### 2. 로그인 상태 UI 변경

- **네비게이션 영역**
  - "내 게임" 버튼 표시
  - "게임 만들기" 버튼과 Add 아이콘 표시
  - 사용자 아바타 이미지 표시
  - 아바타 클릭 시 드롭다운 메뉴 표시
  - 드롭다운 메뉴에 "로그아웃" 버튼 표시

### 3. 네비게이션 기능

- **로고 클릭**
  - 로고 클릭 → 홈페이지 유지 (현재 페이지)

- **로그인 버튼 (비로그인 상태)**
  - "간편로그인해서 게임 만들기" 클릭
  - 개발 환경: 자동 로그인 처리
  - 프로덕션 환경: `/login/kakao` 페이지로 이동

- **내 게임 버튼 (로그인 상태)**
  - "내 게임" 버튼 클릭 → `/dashboard` 페이지로 이동

- **게임 만들기 버튼 (로그인 상태)**
  - "게임 만들기" 버튼 클릭 → `/create` 페이지로 이동

- **로그아웃 기능 (로그인 상태)**
  - 아바타 클릭 → 드롭다운 메뉴 표시
  - "로그아웃" 버튼 클릭 → 로그아웃 처리 및 UI 변경 (비로그인 상태의 네비게이션 표시)

- **테마 토글**
  - 태양 아이콘 클릭 → 테마 변경 (light - dark)

### 4. 게임 섹션 기능

- **게임 더 보기**
  - "게임 더 보기" 버튼 클릭 → `/games` 페이지로 이동

- **게임 카드 클릭**
  - 게임 카드 클릭 → 게임 미리보기 다이얼로그 표시
  - 다이얼로그에 게임 제목, 제작자, 문제 수 표시
  - "게임 시작" 버튼 클릭 → `/game/[gameId]` 페이지로 이동
  - "닫기" 버튼 클릭 → 다이얼로그 닫힘

- **게임 카드 정보**
  - 게임 썸네일 이미지 표시
  - 게임 제목 표시
  - 문제 수 표시
  - 공유 상태 표시 (공유된 게임인 경우)

### 5. 로딩 및 에러 상태

- **초기 로딩**
  - 데이터 준비 전: 게임 카드 스켈레톤 UI 표시
  - 데이터 준비 후: 실제 게임 데이터 로딩

- **에러 상태**
  - 게임 데이터 로딩 실패 시: "게임을 불러오는 중 오류가 발생했습니다." 메시지 표시

### 7. 인증 상태 전환

- **로그인 → 로그아웃**
  - 로그인 후 UI 변경 확인
  - 로그아웃 후 원래 UI로 복원 확인
  - 로컬 스토리지 유저정보 정리 확인

## 우선순위

- **Critical**: 네비게이션 기능, 게임 카드 클릭, 인증 상태별 UI
- **High**: 로딩/에러 상태, 로그인/로그아웃 기능

## 테스트 데이터 요구사항

- **기본 게임 목록**: 4개의 샘플 게임
- **사용자 정보**: 프로필 이미지, 닉네임
- **MSW 설정**: 개발 환경에서 API 모킹
