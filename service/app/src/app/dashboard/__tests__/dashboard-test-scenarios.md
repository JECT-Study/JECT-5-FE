# 대시보드 E2E 테스트 시나리오

> 🎮 **대시보드 화면의 E2E 테스트 시나리오 문서**

## 📋 개요

이 문서는 대시보드 화면의 E2E 테스트 시나리오를 정의합니다. 접근성 가이드라인을 준수하여 작성되었으며, 실제 사용자 행동을 기반으로 한 테스트 케이스들을 포함합니다.

## 🎯 테스트 환경

- **화면**: 대시보드 (DASHBOARD, 화면 번호 201)
- **전제 조건**: 로그인 상태
- **접근성**: 접근성 기반 셀렉터 사용 (getByRole, getByLabel, getByText)

## 📝 테스트 케이스 목록

### 대시보드 네비게이션 테스트

#### 1.5 '게임 시작' 버튼 기능 확인
- **테스트 절차**:
  1. 게임 카드를 클릭하여 게임 미리보기 팝업을 띄운다
  2. '게임 시작' 버튼을 클릭한다
- **기대 결과**: '참가자 설정' 화면(GAME_PARTICIPANT, 화면 번호 501)으로 이동한다
- **비고**: 로그인 상태 필요

#### 1.6 '내 게임' 버튼 기능 확인
- **테스트 절차**: '내 게임' 버튼을 클릭한다
- **기대 결과**: 대시보드 화면으로 이동한다
- **비고**: 로그인 상태 필요

#### 1.7 '게임 만들기' 버튼 기능 확인
- **테스트 절차**: '게임 만들기' 버튼을 클릭한다
- **기대 결과**: 게임 만들기 화면으로 이동한다
- **비고**: 로그인 상태 필요

#### 1.8 로그아웃 기능 확인
- **테스트 절차**:
  1. '아바타' 버튼을 클릭한다
  2. '로그아웃' 버튼을 클릭한다
- **기대 결과**: 로그아웃 된다
- **비고**: 로그인 상태 필요

### 2. 대시보드 화면 테스트

#### 6.1 대시보드 진입 시 내 게임 목록 확인
- **테스트 절차**: 홈(로그인) 화면에서 '내 게임' 버튼을 클릭한다
- **기대 결과**: 대시보드 화면(DASHBOARD, 화면 번호 201)이 정상적으로 표시되고, 작성한 게임의 제목이 최신 순으로 나열된다
- **비고**: 로그인 상태 필요

#### 6.2 게임 옵션 버튼 기능 확인
- **테스트 절차**: 각 게임 카드에 있는 '게임 옵션' 아이콘을 클릭한다
- **기대 결과**: 세 가지 옵션(게임 미리보기, 게임 수정, 게임 공유) 메뉴가 표시된다
- **비고**: 로그인 상태 필요

#### 6.3 '게임 수정' 팝업 기능 확인
- **테스트 절차**:
  1. '게임 옵션' 아이콘 버튼을 클릭한다
  2. '게임 수정' 버튼을 클릭한다
- **기대 결과**: 게임 만들기 화면으로 이동하여, 해당 게임의 내용을 수정할 수 있다
- **비고**: 로그인 상태 필요

#### 6.4 '게임 공유' 팝업 기능 확인
- **테스트 절차**:
  1. 라이브러리로 공유를 원하는 게임의 '게임 옵션' 아이콘 버튼을 클릭한다
  2. '게임 옵션' 메뉴에서 '게임 공유' 버튼을 클릭한다
- **기대 결과**: '203. alert - 게임 공유' 팝업이 뜬다
- **비고**: 로그인 상태 필요

#### 6.5 '게임 공유' 기능 확인 (긍정)
- **테스트 절차**: alert-'게임 공유' 팝업이 뜬 상태에서 '네' 버튼을 클릭한다
- **기대 결과**: 해당 게임이 라이브러리에 공유되고, 게임 카드에 '공유' 배지가 표시된다
- **비고**: 로그인 상태 필요

#### 6.6 '게임 공유' 기능 확인 (부정)
- **테스트 절차**: alert-'게임 공유' 팝업이 뜬 상태에서 '아니오' 버튼 또는 팝업 영역 밖을 클릭한다
- **기대 결과**: 팝업이 사라진다
- **비고**: 로그인 상태 필요

#### 6.7 '게임 공유 취소' 팝업 기능 확인

  1. 라이브러리로 공유된 게임의 '게임 옵션' 아이콘 버튼을 클릭한다
  2. 게임 옵션 메뉴에서 '게임 공유 취소' 버튼을 클릭한다

## 🔧 테스트 데이터 요구사항

### 필수 테스트 데이터
- **로그인된 사용자**: 테스트용 사용자 계정
- **게임 데이터**: 
  - 공유된 게임 (공유 배지 표시)
  - 공유되지 않은 게임 (공유 배지 미표시)
  - 최소 2개 이상의 게임 카드

### 테스트 환경 설정
- **MSW**: API 모킹을 위한 Mock Service Worker 설정
- **인증**: 로컬 스토리지 및 쿠키 기반 인증 모킹
- **데이터**: 테스트용 게임 데이터 준비

## ⚠️ 주의사항

1. **접근성 우선**: 모든 셀렉터는 접근성 기반으로 작성
2. **테스트 격리**: 각 테스트는 독립적으로 실행 가능해야 함
3. **상태 관리**: 테스트 간 상태 공유 금지
4. **에러 처리**: 네트워크 오류, 로딩 실패 등 예외 상황 고려
5. **타임아웃**: 적절한 대기 시간 설정

## 📊 테스트 커버리지 목표

- **기능 커버리지**: 100% (모든 테스트 케이스 구현)
- **접근성 커버리지**: 키보드 네비게이션, 스크린 리더 지원
- **에러 케이스**: 네트워크 오류, 인증 실패 등
- **크로스 브라우저**: Chrome, Firefox, Safari 지원
